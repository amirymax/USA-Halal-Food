# USA Halal Food Bot — Telegram-бот для поиска халяльных ресторанов в США

**USA Halal Food Bot** — это Telegram-бот, разработанный на Python с использованием библиотеки `aiogram`, который помогает быстро находить халяльные рестораны по городам США. Информация берётся из json файла.

---

## 🎯 Возможности

- 📍 Поиск халяльных ресторанов по названию штата 
- 🍽️ Отображение названия, адреса и контактных данных ресторана
- 🔎 Быстрый доступ к информации прямо из Telegram
- 📁 Хранение и обновление базы данных в удобном формате
- 👤 Простое взаимодействие: `/start` и ввод города

---

## 🛠️ Технологии

- Python 3.10+
- [aiogram 3.x](https://docs.aiogram.dev)
- Хранение данных: CSV, JSON
- Асинхронный парсинг

---

## 💡 Как использовать

1. Найдите бота в Telegram и запустите его: `/start`
2. Выберите название штата, например: `NY`
3. Бот покажет список халяльных ресторанов с адресами и телефонами

---

## 🧾 Установка и запуск

1. Клонируйте репозиторий:
```bash
git clone https://github.com/amirymax/usa-halal-food.git
cd usa-halal-food
```

2. Установите зависимости:
```bash
pip install -r requirements.txt
```

3. Создайте `.api_token.py` файл и добавьте токен:
```env
BOT_TOKEN=ваш_токен_бота
```

4. Запустите бота:
```bash
python main.py
```
